# Danmaku Echo 专属动效清单

设计基线：2.3.4，2026-10-21；代码实施：2026-10-22。本文同时记录设计规范、实施落点与验收范围。
视觉沿用[设计系统](DESIGN_SYSTEM.md)与用户主题色；行为遵循 [AGENTS.md](../AGENTS.md)。

## 1. 动效方向

**操作立即得到回应，内容变化有来有回，观看直播时保持安静。**

- 核心记忆点：收藏轮盘松开发送后，扇区与 bot 一起收缩并消失，不等待响应；成功或失败统一使用顶部文字提示。
- 连续性：收藏房间列表进入详情、返回原位置，以及置顶、排序、移除后的行位置变化。
- 日常反馈：开关、按钮、菜单、真实统计变化；只强调正在操作的局部。
- 预算：直播画面、原生弹幕轨道与悬停命中不参与装饰性动画。设置页不逐段入场，长列表不整批飞入。

“丝滑”的优先级是：不裁切、不跳布局、不阻塞操作、可中断，然后才是增加动效。

## 2. 当前基础与缺口

本表记录实施前的代码基础；完成情况与实际验证见第 7、9 节，不由“代码存在”推断真实直播间已验收。

| 区域 | 已有基础 | 本轮设计重点 |
| --- | --- | --- |
| 设置页 | 按钮约 140ms、开关 200ms 回弹、原生平滑锚点滚动 | 统一反馈与中断规则，不增加整页切换动画 |
| 收藏面板 | 遮罩 160ms、面板入场 190ms、房间详情入场 160ms | 补上返回方向、滚动与焦点连续性 |
| 收藏列表 | 初次 50 项，后续每次追加 50 项；已有加载骨架 | 局部重排、局部新增、保留旧数据，避免整表重播 |
| 收藏轮盘 | 入场 180ms、收缩 240ms、结果入场 200ms、结果停留 900ms | 后续调整为整个轮盘收缩完成就移除，不等待响应（见 M12） |
| 雷达 | 首次说明 200ms；队列进入 220ms、离开 160ms、移动 260ms | 复用现有 WAAPI 与清理逻辑，不另建队列动画系统 |
| 统计 | 真实异步进度、静态汇总数字 | 汇总数字短过渡、加载占位，不能伪造进度 |
| 弹幕操作 | 按钮反馈；抖音胶囊透明度 90ms、toast 180ms | 以命中稳定为先，仅统一适用的视觉反馈 |

## 3. 节奏与参数

下表是本次采用的节奏。沿用既有组件的合适参数，仅为新增交互增加局部过渡。

| 用途 | 目标时长 | 变化方式 |
| --- | --- | --- |
| 按钮、选中与悬停反馈 | 140ms | 小面积背景/文字颜色；按钮视觉层按压至 0.97 |
| 开关 | 200ms | 滑块平移，轻微回弹；外部点击区域固定 |
| 面板/小菜单进入 | 180–200ms / 140ms | opacity 与最多 8px 位移 |
| 面板/小菜单退出 | 120–160ms | opacity 为主；点击关闭即结束可交互状态 |
| 收藏详情进入/返回 | 180ms | 最多 8px 水平位移，进入向左、返回向右收敛 |
| 收藏行重排 | 220ms | 只对受影响可见行做位置过渡 |
| 雷达队列 | 220 / 160 / 260ms | 保留现有进入、离开、重排参数 |
| 轮盘发送 | 240ms | 整个轮盘（含 bot）scale 1 → 0.18、opacity 1 → 0，完成即移除 |
| 轮盘结果 | 无结果动画及额外停留 | 结果沿用顶部文字提示，轮盘收起无需等待 sender |
| 汇总数字 | 220ms | 从当前显示值收敛到最新真实值 |
| 列表局部交错 | 间隔 24ms，最多 6 项 | 最大启动延迟 120ms，单项 160ms |

曲线约定：

- 普通进入与位置收敛：`cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 开关轻回弹：沿用设置页 `cubic-bezier(0.2, 0.8, 0.25, 1.15)`；只用于小控件，不用于整页或长列表。
- 雷达：保留 `cubic-bezier(0.22, 1, 0.36, 1)`，无需为统一名称改写成熟逻辑。
- 退出：`ease-out`，不回弹、不等待入场结束。
- 原生平滑滚动的时长由浏览器决定，不强行套用上述毫秒值。长按 180ms、发送冷却、雷达到期与休眠时间属于业务时序，不能当作动效参数调整。

## 4. 可实施清单

优先级：P0 为其他动效的前提，P1 为优先体验改进，P2 为条件满足时才实施。
“保留/增强/新增”描述相对 2.3.4 基线的改动类别；下列项目已接入统一动效策略，实施与验证记录见第 7、9 节。

### A. 通用与设置页

| ID / 优先级 / 状态 | 场景 | 设计与完成条件 |
| --- | --- | --- |
| M01 · P0 · 增强 | 动效基础 | 对本次涉及的组件统一时长、曲线和减少动态效果规则；优先 CSS 变量，JS 动效按需复用小工具。不引入动画框架，不做全仓重构。中途切换系统动效偏好时，取消动画并呈现最终状态。 |
| M02 · P1 · 增强 | 按钮、开关、选择项 | 保留 140ms 按钮反馈与 200ms 开关。设置行只改变背景；缩放施加在视觉层，点击区和焦点轮廓稳定。禁用与忙碌控件不反复弹跳。快速反向切换从当前位置接续，最终状态以真实设置为准。 |
| M03 · P1 · 保留 | 设置侧栏导航 | 保留锚点滚动与当前分组高亮，颜色过渡 140ms。所有设置分组持续可读，不做路由式整页淡出、不随滚动反复入场。初始 hash 与历史定位直接到位；用户滚动可打断导航滚动。 |
| M04 · P2 · 新增 | 条件设置与示意切换 | 仅对用户操作后新出现的局部内容做 140ms 透明度过渡；先提交布局，再显示内容，不逐帧动画化高度。收藏说明页的列表/轮盘示意可交叉淡入，但不自动轮播、不模拟真实发送。 |

### B. 收藏面板与列表

| ID / 优先级 / 状态 | 场景 | 设计与完成条件 |
| --- | --- | --- |
| M05 · P1 · 增强 | 打开/关闭收藏 | 保留面板入场，退出 120–160ms。关闭请求立即禁用面板操作；焦点约束在退出期间仍有效，结束后恢复入口焦点。快速重开取消旧退出，避免旧回调移除新面板。 |
| M06 · P1 · 增强 | 房间 → 收藏详情 → 返回 | 采用 180ms 轻水平过渡并明确返回方向。稳定房间 ID；保存来源滚动位置，返回后恢复被点击房间的焦点。详情默认定位顶部，不能因动画继承错误滚动位置。 |
| M07 · P2 · 新增 | 房间名称共享元素 | 在 M06 稳定后，可让被点击房间的名称/图标与详情标题连续过渡，最长 220ms。限定在收藏面板内部；功能探测失败直接采用 M06，不建立全站截图过渡或重复可访问标题。 |
| M08 · P1 · 新增 | 置顶、排序、移除、移动 | 使用稳定收藏 ID 与 Vue 列表过渡或 FLIP（先测量位置差，再用 transform 收敛），220ms，仅作用于受影响的可见行。拖动中的行跟随指针，不叠加回弹；松手后邻行归位。操作失败恢复真实顺序；被删除行的焦点移至相邻行或空态入口。 |
| M09 · P1 · 新增 | 新增/加载更多 | 保持现有 50 项分页。仅新进入视口的最多 6 项按 24ms 交错，单项透明度与最多 4px 位移 160ms；其余直接显示。搜索输入与每次筛选不重播整表，焦点项立即显示。 |
| M10 · P0 · 增强 | 首次加载与刷新 | 初次无数据时复用真实行高的骨架，容器标记 `aria-busy`；快速加载不人为延时。已有数据刷新时保留旧列表与滚动位置，局部提示更新中。加载结束即移除骨架，空结果进入真实空态；减少动态效果时使用静态骨架。 |
| M11 · P2 · 条件新增 | 窄屏排序/操作菜单 | 仅当现有菜单因窄屏难以触达时改为底部抽屉，进入 200ms、退出 160ms、底部最多 24px 位移，背景适度压暗。提供标题、关闭、Escape、焦点约束与恢复、内部滚动、安全区；嵌套在收藏面板时只让顶层响应 Escape。收藏轮盘不套用抽屉或遮罩。 |

M08 与 M09 同时触发时，只让保留行重排、新行入场；不要在同一元素上叠加两组 transform。
离场行不能撑起新的空白区域，也不能使用户指针下的“发送”意外换成另一条收藏；位置变化期间保留稳定目标校验。

### C. 轮盘：重点保留的完整时序

**M12 · P0 · 保留并验收。** 这是已有交互，不另做一套发送流程。

| 时刻/事件 | 扇区 | 中心 | 交互规则 |
| --- | --- | --- | --- |
| 打开 | 保留 180ms 入场 | 原 bot，保留既有眼睛交互 | 沿用当前缩放与命中计算 |
| 松开发送，进入 sending | 当帧启动 240ms 收缩淡出 | 与整个轮盘一起收缩淡出 | 立即锁定选择，隐藏上下提示框，释放鼠标交互 |
| 收缩完成，可能仍在等待响应 | 移除 | bot 及交互层一同移除 | 不等待 sender，发送锁继续防重复，不保留遮挡画面的元素 |
| 返回成功/失败 | 已移除；若动画尚未完成则立即关闭 | 不显示勾叉或 bot | 沿用 sender 顶部文字提示，不等待收藏计数保存，不影响新打开的界面 |
| 关闭、切房、销毁或重新打开 | 沿用既有取消/重置语义 | 旧结果失效 | 旧请求不得复活反馈或关闭新面板 |

- 响应不足 240ms：直接关闭整个轮盘，不为播放完收缩动画延迟关闭。
- 响应很慢：轮盘与 bot 已移除，不增加闪烁、倒计时或中心文字框；长等待与超时按现有发送协调器处理。
- 失败或异常：关闭轮盘，沿用顶部错误文字提示，不增加抖动惩罚、不自行重试。
- 减少动态效果、性能模式或动画 API 不可用：发送时直接移除整个轮盘，顶部文字提示保留。
- 验收背景始终透明，不出现白色底盘或全屏遮罩。视觉过渡不得改变扇区选择、中心取消区和缩放后的命中规则。

| M17 · P0 · 保留/局部增强 | 胶囊与操作提示 | 胶囊优先短透明度变化，保留现有抖音 90ms；不得为淡入先隐藏命中目标，不上下漂移、不改变平台原生轨迹。按钮保持 140ms，适用的 toast 沿用 180ms；同一操作不重复弹出提示。轮盘结果只使用顶部文字提示，轮盘不保留勾叉或结果停留。 |

## 5. 七类动效如何用在本项目

原始需求标题为“8 种”，实际列出 7 种；这里按这 7 种映射具体用途，不补造第八类。

| 类型 | 对应清单 | 使用边界 |
| --- | --- | --- |
| 共享元素过渡 | M06、M07 | 优先解决房间/详情的关系与返回位置，共享标题属于可选增强 |
| 弹簧动画 | M02 | 小控件轻回弹；不用于弹幕轨道、列表整页与错误反馈 |
| 微交互 | M02、M12、M17 | 真实操作立即反馈；发送结果必须等待真实响应 |
| 骨架屏 | M10、M16 | 首次缺少内容才出现；刷新保留旧内容 |
| 交错动画 | M09 | 只处理少量新可见行，不随滚动重播 |
| 底部抽屉 | M11 | 窄屏操作确有需要再用；不改变轮盘透明背景 |
| 数字滚动 | M15 | 仅真实汇总变化，不用于倒计时、未知数据或装饰数字 |

## 6. 性能、无障碍与生命周期

- 默认内容可见；动画 API 不可用时直接显示最终状态。减少动态效果时，停止位移、回弹、缩放、交错、眨眼、骨架流光与数字滚动；保留颜色、图形、文字和焦点反馈，直接切换。
- 页面隐藏、组件卸载或面板关闭时清理 animation、rAF、监听器与定时器。现有 bot 眨眼和骨架加载只在可见且需要时运行，不新增常驻循环。
- 只为本次受影响的可见收藏行测量位置；批量读取后再写样式，不全 document 扫描、不每帧计算布局。动画结束移除临时 `will-change`。
- 各操作可中断：新状态替代旧状态，不排队播放过时动画；旧异步请求回调必须校验当前界面/请求身份。
- 持续阅读内容不位移。悬停胶囊、拖动行、轮盘与播放器全屏坐标沿用当前计算；不修改平台原生弹幕暂停、速度和轨道模型。
- 目标是在 60Hz 设备上接近每帧 16.7ms 的预算；这只是验收目标，不能当作已经测得的结果。用实际直播负载检查新增动效造成的布局与长任务，发现明显争用时首先减少参与行数或取消非必要位移。
- 焦点不等待入场才可用，离场元素不可再次触发业务操作。图标状态有可访问名称，不仅凭红绿颜色表达结果。

## 8. 验收清单

### 功能与边界

- [ ] 设置页独立窗口与扩展弹出窗口均可滚动；检查 800×600、390×700、320×568，以及 640×300 矮窗口中的弹层底部操作。
- [ ] 中文/英文、长收藏文字、空列表、超过 50 项、不同主题色下不裁切、不重叠、不引入横向滚动。
