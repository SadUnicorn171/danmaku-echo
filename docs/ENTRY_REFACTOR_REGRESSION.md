### 本轮发现并修复的问题

- Chrome/Edge 152 在当前 Windows headless 环境中会因 GPU 子进程异常退出。浏览器夹具在 Windows 使用一次性测试配置的进程内 GPU，并禁用 Skia Graphite；不改变扩展产物和真实浏览器配置。
- 浏览器子进程结束后，测试运行器过早读取输出；现改为等待输出流关闭，并允许从本次 JSON 产物恢复结果。
- 旧 JSON/截图可能被下一次同名场景误用；每次运行前先删除该场景的精确产物文件。
- 雷达首次说明会遮挡 fixture 操作；夹具准备阶段会确认说明，产品的首次说明行为保持不变。
- 收藏排序测试仍查询旧原生 `select`；现改为操作当前自定义排序菜单。
- 斗鱼第 18 个表情分类和发送成功反馈可能晚于固定等待时间；现按原生表情点击与反馈终态轮询，并保留总超时。
- headless Chromium 偶发暂停单个 RAF/定时器约 2 秒；Bilibili 性能夹具新增调度暂停识别，不再把宿主调度暂停误算为扩展同步耗时。

浏览器 E2E 仍是本地可选测试，未加入 CI，也未修改 CI 工作流。
