# Danmaku Echo 设计规范

## 设计命题

弹幕回声是直播画面里的快捷工具，不是独立内容平台。界面应当低打扰、直接、紧凑，并与 `+1` 操作形成同一套视觉语言。

标志性元素是“橙色回声轨”：一条连续的橙色线或一组沿同一轴线排列的橙色标记，用来表达弹幕在不同直播间之间被收藏和再次发送。它只用于当前范围、当前选择和主要动作，不作为装饰铺满页面。

## 色彩

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 回声橙 | `#FD8101` | `+1`、发送、当前选择、焦点轨迹 |
| 纸白 | `#FFFFFF` | 直播间收藏浮层与插件设置页主表面 |
| 暖白 | `#FFF8F1` | 输入框、当前房间条与轻量悬停表面 |
| 墨色 | `#241A14` | 标题与正文 |
| 石灰 | `#8B7D73` | 次要说明和元数据 |
| 成功色 | `#27AE60` | 成功反馈弹窗 |
| 失败色 | `#FF4747` | 失败反馈弹窗和错误状态 |
| 警告色 | `#E6A000` | 危险或需要注意的反馈弹窗 |

平台允许自定义 `--bcp-action-start` 和 `--bcp-action-end` 时，收藏面板的主要动作应继承这两个变量，并以 `#FD8101` 作为回退值。

收藏界面的局部中性色使用暖白 `#F7F5F2`（输入与说明示意容器）、浅橙 `#FFF0E0`（当前范围）、细分隔线 `#EEE7E1`、说明文字 `#6F6259` 与元数据 `#75695F`。收藏发送按钮与轮盘选中项使用主题色底、墨色 `#241A14` 文字；浅橙选中范围使用 `#853F00` 文字。该约定适用于收藏与收藏说明，真实直播弹幕胶囊继续读取各平台配色设置。

## 字体

- 标题与正文：`"Segoe UI", "Microsoft YaHei UI", "PingFang SC", sans-serif`
- 数字、快捷键与 `+1`：`Bahnschrift, "Segoe UI", sans-serif`
- 标题使用 500–600 字重；避免超大粗体和营销式英文眉题。

## 结构

### 直播间收藏面板

```text
  书签图标  收藏弹幕                                ×
  当前直播间 / 房间名                               3 条
  本房收藏 3     其他直播间 8      全部 11        搜索
  其他直播间 / 先选择直播间                 排序：发送次数
  ────────────────────────────────────────────────────
  A 直播间 / 3 条收藏 / 已发送 14 次                ›
  ────────────────────────────────────────────────────
  B 直播间 / 2 条收藏 / 已发送 7 次                 ›
  ────────────────────────────────────────────────────
  Alt+Q 短按打开  Alt+Q 长按轮盘  1-9 快速发送  Esc 关闭
```

选择直播间后替换为独立弹幕页：

```text
  ‹  A 直播间 / 8 条收藏              排序：发送次数
  ──────────────────────────────────────────────
  1  弹幕内容 / 收藏时间与发送次数
     置顶  标签  加入本房  移除                  发送
  ──────────────────────────────────────────────
  2  弹幕内容 / 收藏时间与发送次数
     置顶  标签  加入本房  移除                  发送
```

- 设计先在 Pencil 完成，再映射至 Vue 与 SCSS；可编辑文档、四张画板与验收记录见 [收藏设计交付记录](design/pencil-favorites/README.md)。
- 面板只有一个白色主表面，18px 圆角、最大宽度 720px；标题使用橙色书签图标，标题 24px、680px 以下 21px，收藏正文 15px。桌面水平留白 24px，窄屏 18px。
- 列表使用细分隔线形成连续阅读流，不为每条内容添加卡片。列表内部滚动，底部快捷键栏保持可达；正文与操作分行，长正文最多展示两行，完整内容仍保留在数据和标题提示中。
- 当前直播间通过图形、文字和数量共同表达，选中范围使用浅橙背景与深色文字，不能只依赖颜色。
- 本房收藏直接展示弹幕；“其他直播间”和“全部”先展示直播间，点击后进入独立弹幕页，不允许多个直播间行内展开。
- 默认按发送次数降序；用户可切换“轮盘顺序”后拖动弹幕调整轮盘中的排列，行内上移/下移按钮作为键盘与精确操作的替代入口；也可切换时间倒序或时间正序，排序只改变弹幕顺序，不打乱直播间层级。
- 保留搜索、标签编辑、置顶、移除确认、加入本房、发送、加载更多与键盘快捷键。`发送` 使用 16px 圆角胶囊和深色文字，位于操作行右侧；次要操作保持文字化。

### 收藏快捷轮盘

- 轮盘无白色底盘与全屏遮罩；360px 外径、108px 内径的饼状环由半透明墨色 `#241A14CC` 扇区组成，扇区间留 3° 透明缝隙。未选中文字为白色，选中扇区使用主题色与墨色文字。76px 原机器人位于透明中心间隙，选项标签保持水平，弹幕文字前不放图标。设置页示意复用相同扇区几何。
- 收藏轮盘中心使用主题色圆形机器人表情，两枚胶囊眼睛跟随指针方向，表情内部不叠加文字；待机时偶尔眨眼，选中收藏、其他房间和更多入口时分别给出兴奋、疑惑和眨眼反馈；颜色继承 `--bcp-action-start` 与 `--bcp-action-end`，不引入第二主色。
- 松开发送即启动 240ms 扇区收缩淡出，等待已有 sender 真实结果时仅保留原 bot，并锁定选择。收缩不等待结果，结果返回也不重播收缩动画。成功切换为浅绿底与绿色勾 `#168243`，失败切换为浅红底与红色叉 `#BD3038`，均停留 900ms 后关闭。发送后不显示上下文字提示框，发送中与结果文案仅提供给辅助技术。取消、重新打开、切房或销毁后旧结果不得恢复反馈或关闭新界面。减少动态效果时立即隐藏扇区并直接切换状态，不做收缩与入场动画。
- 始终读取当前直播间的“轮盘顺序”，展示前 6 条收藏和“其他直播间”“更多”两个导航项；调整顺序后，下一次打开立即使用新排列。
- 圆盘、顶部提示、底部说明共同缩放。以实际可见的 `document.documentElement.clientWidth/clientHeight` 计算空间，仅在无有效值时回退到 `innerWidth/innerHeight`；基础整体占用按 360×526px 预留，并保留 12px 边距，避免滚动条占位导致裁切。指针位移除以同一缩放系数后再命中，中心取消区同步缩放。窗口 resize 取消未完成的手势，随后松开快捷键不得发送。
- 长文案只读预览最多两行省略，完整数据、选项标题与辅助名称仍保留；顶部快捷键提示与下方松开／取消提示保持可见，不增加可滚动说明区，以免持键选中手势与滚动冲突。
- `prefers-reduced-motion` 下停止入场、眨眼、表情过渡、选中放大与按钮按压缩放，直接显示状态；几何缩放与命中规则保持一致。

### 插件收藏说明页

- 使用一张连续白色说明面，不叠加 Hero 卡、功能卡和步骤卡。
- 左侧用书签图标解释收藏价值，右侧提供“收藏列表 / 快捷轮盘”两种可切换示意；窄屏改为单列。两种示意均明确标注“示意 / Example”，中英文内容随设置页语言切换，不使用虚构的用户数据或统计。
- 下方步骤仅在真实顺序中使用 1–3 编号：收藏 → 短按列表 → 长按轮盘。
- 保留本机存储说明与现有数据管理工具。示意仅演示结构，不触发发送；动效遵循 `prefers-reduced-motion`。

### 雷达首次说明

- 设计先在 Pencil 完成，再映射至共享雷达 UI；桌面、窄窗口、展开设置与交互规范的画板、截图和验证记录见 [Pencil 交付记录](design/pencil-radar-onboarding/README.md)。
- 使用单一白色说明面、18px 圆角和暖灰细分隔线；桌面宽度最多 460px、水平留白 24px，480px 以下留白 18px。标题依次为 24px、480px 以下 21px、340px 以下 19px。标题旁复用雷达图形，图标、按钮和面板不叠加阴影。
- 保留入口指向、最近一分钟统计、提示队列与拖动说明，优先突出「默认只提醒」。七项可调设置使用原生 `details` / `summary` 默认折叠，展开后展示完整说明并重新计算入口箭头位置。
- 自动 +1 选项独立放在行为说明后，默认关闭并读取保存状态，使用主题色浅底；保留发送冷却与平台限制说明，不能与「知道了」捆绑开启。
- 标题、正文采用墨色和暖灰保证阅读对比，主题色集中用于雷达标识、开关和主操作；主按钮使用深色文字。主题色继承现有平台变量，默认回声橙 `#FD8101`，不覆盖用户配色。
- 说明正文独立纵向滚动，底部操作栏不参与滚动；44px 胶囊操作在窄、矮窗口中保持可达，并留出安全区。「知道了」使用文字下划线表示键盘焦点，不增加边框；动态获取可聚焦控件，保持 Tab 循环与 Escape 确认后的队列或入口焦点恢复。
- 入场使用 200ms 淡入和轻位移，开关滑块轻回弹，按钮按压缩至 97%；`prefers-reduced-motion` 下直接呈现最终状态，取消入场、过渡和按压缩放。首次确认键、队列恢复、检测与发送逻辑继续沿用现有语义。

## 动效

- 面板进入 160–200ms，只使用透明度和位移。
- 悬停与按压 140ms，与现有 `+1` 操作一致。收藏面板关闭/返回按钮按压缩至 94%，设置行只做背景色过渡，不改变布局或开关尺寸。
- 设置页按钮按压缩至 97%；开关滑块用 200ms 轻回弹曲线，命中区不变。共享元素、骨架屏、交错动画、底部抽屉和数字滚动按实际场景选用，完整约束见 `AGENTS.md` 的「设置页设计与动效」。
- 不使用装饰性漂浮、光斑、循环动画或大面积玻璃模糊。
- 始终支持 `prefers-reduced-motion`，设置开关在减少动态效果时即时切换。

## 禁止模式

- 有底色或边框的按钮、图标不叠加装饰性阴影或多圈光晕。阴影主要用于区分浮层与页面，保持单层、低强度；雷达首次说明的入口图标仅用橙色边框强调，「知道了」按钮的键盘焦点使用文字下划线。
- 青绿、紫色等第二主色与 `#FD8101` 竞争。
- 每一条信息都放进圆角阴影卡片。
- 英文眉题、无意义的大数字和装饰性渐变。
- 图标外再套独立彩色方块，形成组件库模板感。
- 仅靠颜色区分当前房间、其他房间或危险操作。


## 统计与收藏列表

发送统计沿用白色和主题橙色，筛选、分页与状态提示不添加阴影。全历史汇总与筛选结果分开说明；日期筛选和日汇总标明 UTC，空正文与旧记录未保存正文应区分。收藏面板初次最多展示 50 项，列表下方的“加载更多”每次追加 50 项，前 9 项快捷键保持原有顺序。

## 胶囊与雷达自动大小

- 大小模式与雷达触发档位独立。自动触发只决定触发次数；停留时间、队列上限、提示大小继续读取各平台保存的参数。
- 大小模式默认为手动，兼容已有用户的胶囊百分比与雷达提示百分比。切换模式不重置这些值。
- 自动大小以 3840×2160 计算：浏览器报告的 screen 宽高乘 devicePixelRatio 估算显示像素，取宽、高相对比例的较小值。低于该分辨率时，在原缩放结果上增大 30%，最多达到用户设置的初始大小；最终仍限制为 50%–200%。无有效屏幕数据时使用手动大小。
- 雷达入口使用相同比例，提示框可在各平台参数中调整基础百分比。调整后同步重排提示框与悬停命中区域。
- 页面启动、设置变化、窗口 resize 与重新获得焦点时更新。浏览器缩放会影响像素比，因此自动大小也会随之重新计算；手动模式保持原有缩放语义。
- 抖音 MAIN world 通过已有 Renderer 设置消息接收最终百分比，不新增通信协议或浏览器权限。

## 运行日志工具

常规设置内使用现有设置卡片，展示本地保留范围与「导出日志 / 最近发送失败 / 清空日志」三个操作。操作期间禁用按钮，成功和失败沿用全局状态提示，不增加常驻浮层或顶部栏按钮。

## 设置页细节

- 「抖音直播净化」复用 `SettingSwitch` 提供三个独立开关，默认关闭，保留白色和主题色，不增加阴影。辅助说明明确总开关/平台开关条件、停用不会反转官方状态，以及直播页异常时的重试入口；中英文同步提供。
- 品牌区下方提供独立「中文 / English」按钮，默认中文，点击即时切换设置页并将 `settingsLanguage` 保存到 `chrome.storage.sync`。浏览器管理的扩展名称与直播页文案仍沿用原有语言机制。
- 设置页沿用侧栏、顶部栏和单列滚动内容区，视觉以 Pencil 设计稿为准（见 `design/pencil-settings/README.md`）。白色分组表面搭配 `#F7F5F2` 暖底，18px 分组圆角、24px 组内水平留白、细内嵌分隔线，不添加卡片阴影。正文 `#241A14`，辅助文字 `#75695F`；这些更深的辅助文字用于保证设置页小字号对比度。
- 保留回声橙 `#FD8101` 作为选中开关及预览胶囊颜色，导航选中态为 `#FFF0E0` 浅底、`#934800` 文字与 600 字重；绿色仅保留成功反馈语义。胶囊预览使用深色文字提高可读性，真实直播胶囊仍读取平台配色设置。
- 版本号沿用系统数字字体；顶部标题 24px、分区标题 19px、设置项 15px、说明 12–13px。桌面侧栏 248px，内容宽度最多 1064px；700px 以下转为横向滚动导航和单列内容。完整功能入口始终保留。
- 工具栏弹窗与完整设置标签页共用页面，但弹窗在挂载前通过扩展视图类型识别，根元素提供 800×600px 固有尺寸，应用框架固定在实际视口内，内容区内部滚动。浏览器窗口较小时，内部布局适应浏览器分配的可用空间。不要仅用 `100dvh` 撑开依赖内容自动定尺寸的弹窗；完整设置标签页继续随视口响应。浏览器回归必须实际调用 `chrome.action.openPopup()` 检查首次打开、小窗口和重新打开，不能只用普通标签页模拟弹窗尺寸。
- 常规设置分为交互、大小、运行日志和发送统计组。快捷操作预览读取当前总开关与四项操作开关；只展示状态，不发送消息。中英文文案随现有语言偏好切换。
- 配色字段的默认值说明可换行，恢复默认按钮随翻译文本宽度展开，色值输入框保留可收缩空间。
- 按钮保留清晰的键盘焦点；平台行只在键盘聚焦时显示外框，鼠标点击不额外框选整行。
- 日志工具在紧凑窗口中将操作放到说明下方；禁用按钮不响应悬停高亮。轻量过渡沿用 140ms 和减少动态效果设置。

### 容量、异常和辅助文案（2026-10-11）

- 自动缩放说明固定为「根据屏幕大小自动调整界面大小。」／“Automatically scale the interface to fit your screen.”，算法留在本文。100% 基础大小在 1920×1080、DPR 1 时为约 65%，3840×2160 时保持 100%；本轮没有改变算法。
- 辅助说明尽量一句，保留自动发送默认关闭、本机保存、UTC 日期、删除范围和不可撤销性。复杂清理范围放入确认框，不堆在日常说明中；中英文及中文回退同步维护。
- 统计占用和本地总占用并列呈现，80%／95% 警告使用文字说明与现有警告色。三个年龄清理按钮为次要操作，明确全平台范围。进度展示实际扫描数；只有查询和导出可取消，已提交的清理须执行到完成或可恢复状态。
- 抖音净化正常应用保持安静；5 秒可见时间内未应用才显示一条异常提示，只有「重试／关闭」。提示白底、主题色细边框、无阴影，不自动聚焦；不覆盖发送反馈。停用选项不会替用户恢复抖音原状态。
