# 现有功能优化记录

日期：2026-09-28。范围是现有功能的可靠性、存储成本和交互细节；保持现有白色/主题色、平台适配结构与本地数据语义。后端、账号和云端同步未实现。

## 已完成

| 方向 | 实际变化 | 保留的边界 |
| --- | --- | --- |
| 雷达自动 +1 | 有界待发送队列、过期检查、房间/生命周期校验；关闭、切房和销毁取消排队与等待 | 已开始的平台发送无法撤回；不自动重发失败消息 |
| 发送统计 | V2 日汇总、128 个 ID 一块、事件独立写入；50 条分页、日期/平台/房间/正文筛选；筛选导出与清理 | 正文仍只存文本；总数覆盖全历史，日汇总为 UTC；全文筛选、导出、局部清理仍可能扫描大量记录 |
| 发送反馈与日志 | 区分平台响应确认和页面判定成功；尽力持久化统计写入异常；导出最近一次失败的关联日志 | HTTP 200 不等于业务成功；完全不可写时异常标记也不能保证落盘；诊断日志仍脱敏 |
| 数据兼容 | V1 统计懒迁移并留备份；未来收藏版本拒绝写入；导入差异预览、revision 检查和导入前恢复 | 不保证旧扩展降级可读取 V2 统计；没有跨多次 Storage 调用或跨设备事务 |
| 设置与收藏体验 | 设置叶子字段经后台串行合并，保留未知字段和失败草稿；收藏初次 50 项、每次追加 50 项；规范化分组去除逐房间全量筛选 | 同一字段按后台写入顺序；收藏前 9 项快捷键和轮盘保持原行为，未改为虚拟滚动 |
| 回归可信度 | 缺失场景结果/断言数组、未注入扩展、fixture 未就绪或进入错误页面时失败；修正抖音 fixture 的 HSTS 和存储执行环境 | 本地模拟页不替代真实直播间验收；未通过的断言明确保留 |

## 验证

- `npm run check` 通过：108 个 Vitest 文件、584 个测试；137 个契约测试。包含类型、lint、构建、架构/manifest 校验和覆盖率检查。最终完整运行使用 Node 24.19.0。
- 统计压力测试在内存 Storage 替身中写入 10,000 条含 1,000 字符正文的事件：V2 汇总不读事件正文；正常追加最多读取 4 个存储 key；无筛选首页 50 条最多读取两个索引块对应的 256 条事件；翻页无重复。它验证 I/O 范围，不代表 Chrome 容量上限或真实耗时基准。
- 2,000 条收藏的组件测试验证初次仅渲染 50 行、追加至 100 行、搜索后重置，以及前 9 项快捷键索引不变。未声称已测得真实页面 FPS 提升。
- 单元测试覆盖自动发送在切房/关闭/过期/销毁后取消、旧统计迁移失败保留原数据、并发追加与清理、收藏未来版本拒绝/导入恢复、两个设置页并发修改、快速反复切换及失败后重试。

本轮选取的 10 个浏览器/场景组合中，9 个通过。抖音最初因测试在 MAIN world 访问扩展存储而中断；修正后 fixture 已就绪，但发送、回复、胶囊间距、富内容收藏预期和禁用恢复等 12 项断言未通过，其中也包括发送统计未产生。脚本仍有“第一版仅文本收藏”的旧预期，并用旧消息方式模拟关闭，需要独立核对其余断言与当前行为，**不能据此宣称抖音交互已验收或四平台全绿**。本轮未因此修改抖音发送/Renderer 架构。

原始产物在本地 `test-results/feature-optimization/`，抖音原始中断和修正后的结果分别保存在 `douyin-side/` 与 `douyin-side-context-fix/`。设置页统计区域已有中英文、800/1280 宽度截图和溢出检查，人工查看未发现布局溢出；未新增阴影。未对真实直播间发送弹幕。
