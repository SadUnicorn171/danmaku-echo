中文

Danmaku Echo 不收集、出售或与第三方共享个人数据。高频 +1 提醒只在当前直播页面内存中统计最近一分钟的相同文字，不持久化或传输分析数据。

本地数据

扩展设置由浏览器的 storage.sync 保存，是否跨设备同步由浏览器账户和浏览器设置决定。弹幕收藏和弹幕雷达首次说明的布尔确认标记保存在 storage.local；确认标记不包含弹幕或账号信息。高频 +1 提醒的计数仅存在于当前页面内存中，刷新或关闭页面后清除。卸载扩展或清除扩展数据可能删除设置、收藏和确认标记。

页面访问与权限

扩展仅在虎牙直播、哔哩哔哩直播、抖音直播和斗鱼直播页面识别弹幕，并通过网站现有的官方输入框和交互控件执行用户明确发起的 +1 或回复操作。scripting 权限用于抖音直播单页路由恢复、受保护的 B 站房间表情后备发送，以及用户主动发送后最多 8 秒的一次性结果观察。虎牙、斗鱼的雷达规模信号只读取当前直播页已显示的贵宾数，不请求、换算或回退到直播热度。提示只保留请求方法、去除查询参数后的路径、HTTP 状态、业务码和官方错误文案；请求体仅在页面上下文内用于识别弹幕请求，不会传出或保存，请求头、Cookie、密码、CSRF、签名和登录令牌也不会传出或保存。

高频 +1 提醒

该功能只对最近一分钟内完全相同的普通文字弹幕进行轻量计数，达到设置门槛后显示“暂不 / +1”提示。B 站和抖音默认基础门槛为 6 次并按页面公开观众数调整；虎牙和斗鱼为 8 次并按页面贵宾数使用独立分档调整。直播热度不再用于估算或回退。它不生成热词、问题、时间线或摘要，不下载模型，也不发送弹幕用于云端分析。

诊断信息

“复制当前页面诊断”只在内存中生成结构化状态，并在用户点击后复制到剪贴板。诊断不包含弹幕正文、用户名、UID、房间号、完整 URL、Cookie、CSRF、收藏内容或请求体；扩展不会自动上传或持久化诊断。

变更与联系

政策变更会在此页面和项目版本记录中公布。问题可通过 GitHub Issues 联系维护者。

English

Danmaku Echo does not collect, sell, or share personal data. Frequent-message +1 reminders count identical text only in current-page memory and do not persist or transmit analysis data.

Local data

Extension preferences use storage.sync. Favorites and one Boolean acknowledging the first radar introduction use storage.local; the acknowledgement contains no danmaku or account data. Frequent-message counts exist only in current-page memory and clear on refresh or close. Uninstalling the extension or clearing its data may remove settings, favorites, and the acknowledgement.

Site access and permissions

The extension recognizes danmaku only on Huya Live, Bilibili Live, Douyin Live, and Douyu Live pages. It uses official editors for user-initiated actions. scripting restores the Douyin runtime, supports the guarded Bilibili room-emote fallback, and runs a one-shot send-result observer for at most eight seconds after a user action. Huya and Douyu radar scaling reads only the guest count already displayed on the current live page; it does not request, convert, or fall back to popularity. Toasts retain only the method, endpoint without query parameters, HTTP status, platform code, and native error text. A request body is inspected only inside the page to identify a danmaku send and is never exported or stored; headers, cookies, passwords, CSRF values, signatures, and login tokens are likewise never exported or stored.

Frequent-message +1 reminder

This feature keeps a lightweight count of identical plain-text messages seen during the last minute and shows a Dismiss / +1 prompt at the configured threshold. Bilibili and Douyin use a default base of 6 and adapt to public viewer values, while Huya and Douyu use 8 and adapt to the displayed guest count with separate bands. Popularity is not used as an estimate or fallback. It does not create hot words, questions, timelines, or summaries, download models, or send danmaku to cloud-analysis services.

Diagnostics

“Copy current-page diagnostics” generates structural state in memory and copies it only after a user click. It excludes danmaku text, usernames, UIDs, room identifiers, full URLs, cookies, CSRF values, favorites, and request bodies. Diagnostics are neither uploaded nor persisted automatically.
