# Microsoft Edge 商店资料（2.3.0）

## 单一用途描述

Danmaku Echo 为虎牙、哔哩哔哩、抖音和斗鱼直播提供统一的弹幕快捷操作：识别侧边聊天与视频弹幕，让用户通过网站官方输入框完成 +1、准备回复、复制弹幕，并把常用弹幕保存在浏览器本地以便再次发送。收藏页支持拖拽设置持久化的“轮盘顺序”，快捷轮盘始终展示当前直播间该顺序的前 6 条；也可使用上移/下移按钮精确调整。2.3.0 统一了四个平台的视频弹幕胶囊尺寸与左右自适应定位，并将弹幕、间隔和胶囊合并为连续悬停区域；发送保护还能显示平台返回的发言频率、重复发送或禁言等限制。哔哩哔哩房间图片表情在官方面板无法唯一定位时，可在校验当前真实房间后使用网页弹幕接口后备发送。

## 许可理由

### 存储理由

`storage` 用于保存用户明确选择的扩展开关、平台样式和操作偏好，并在 `storage.local` 中保存用户主动收藏的弹幕。设置可由浏览器使用 `storage.sync` 同步；收藏不上传、不跨设备同步。升级继续使用 schema v2，不覆盖或清空旧收藏。

### 脚本的合理性

`scripting` 用于抖音单页应用从普通页面无刷新进入直播路由时补充启动扩展包内的直播脚本，也用于用户主动发送哔哩哔哩房间图片表情、官方面板又无法唯一定位资源时，在当前标签页执行一次性后备发送函数。后备函数会校验资源所属房间并调用哔哩哔哩网页正在使用的弹幕接口。两者都不下载或执行远程代码。

### 主机权限的理由

虎牙、哔哩哔哩、抖音和斗鱼匹配范围用于在直播页面识别侧边聊天及视频弹幕、显示用户启用的快捷操作，并驱动页面已有的官方输入框与按钮。`live.bilibili.com/*` 还用于官方表情面板定位失败后的房间图片表情一次性后备发送；`www.douyin.com/*` 用于检测 SPA 路由进入 `/follow/live/*`。扩展不访问其他网站。

## 你用的是远程代码吗？

否。

### 正当性

所有 JavaScript、CSS、图片与依赖都包含在提交的 Manifest V3 扩展包中。扩展没有外部 `<script>`、远程 ES 模块、远程 Wasm、`eval()`、`new Function()` 或动态下载并执行代码的行为。

## 数据使用

不收集用户数据。扩展不会收集、上传、出售或与第三方共享个人身份、网站内容、浏览历史、位置、健康、财务、通信或用户活动数据。设置由浏览器存储；收藏仅保存在 `storage.local`。B 站图片表情后备发送所需 CSRF 凭据只在当前网页内临时使用并提交回哔哩哔哩，不会返回、记录或存储。用户主动复制的脱敏诊断只在内存生成并进入剪贴板，不会自动上传。
